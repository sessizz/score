📺 OBS Studio / Streamlabs Canlı Yayın Entegrasyonu (1 Dakikada Kurulum)

1
OBS'e Tarayıcı Kaynağı Ekleyin:

OBS Studio'da Kaynaklar (Sources) panelinde + (Ekle) butonuna tıklayıp Tarayıcı (Browser) seçeneğini seçin.

2
URL ve Çözünürlüğü Ayarlayın:

URL alanına yukarıdaki /overlay/fenerbahce?theme=topbar linkini yapıştırın. Genişlik: 1920, Yükseklik: 1080 yapın. Arka plan otomatik şeffaftır.

3
Telefondan Skoru Yönetin:

Masa başındaki hakem veya veli/operatör telefonundan /control/fenerbahce adresine girip sayılara bastıkça OBS canlı yayınınızda anında 0 gecikmeyle güncellenir!
