API

Skorboardu kendi uygulamanızdan, script'lerden veya Stream Deck gibi cihazlardan kontrol edin.

API adresi /api/v1/{token}/ ile başlar. Tüm cevaplar JSON'dur.

Erişim

{token}, skorboardun kodudur — kontrol panelindeki adreste /control/ kısmından sonra gelen değer (örneğin /control/fenerbahce → fenerbahce). Skorcu kumanda linkindeki kod da kullanılabilir.

Kontrol panelinde 📺 OBS penceresinin en altında API adresi hazır olarak, kopyala butonuyla birlikte yer alır.

API, skorcu (operatör) yetkisiyle çalışır: sayı, mola, servis, saat, set geçişi ve geri alma yapılabilir. Takım isimleri, kurallar ve maçı sıfırlama yalnızca kontrol panelinden yapılır.

Hızlı başlangıç

# Ev sahibine (Takım A) 1 sayı
curl -X POST https://ALANADI/api/v1/TOKEN/home/score/increment

# Deplasmandan (Takım B) 1 sayı sil
curl -X POST https://ALANADI/api/v1/TOKEN/away/score/decrement

# Skorboardun tamamını oku
curl https://ALANADI/api/v1/TOKEN/

home = Takım A (kontrol panelinde soldaki takım), away = Takım B. POST isteklerinin gövdesi isteğe bağlıdır; gövdesiz istek varsayılan değerle çalışır.

Uç noktalar

Okuma

Uç noktaAçıklama
GET/api/v1/{token}/Skorboardun tüm verisi: takımlar, sayılar, setler, servis, mola, saat, set geçmişi.

Anlık güncellemeler için Server-Sent Events akışı: GET /api/board/{token}/stream (her değişiklikte state olayı gelir).

Sayı

Uç noktaGövdeAçıklama
POST/home/score/increment{"amount": 1}Ev sahibine sayı ekler, servis ev sahibine geçer. Negatif amount sayı siler.
POST/away/score/increment{"amount": 1}Deplasmana sayı ekler, servis deplasmana geçer.
POST/home/score/decrement{"amount": 1}Ev sahibinden sayı siler (0'ın altına inmez).
POST/away/score/decrement{"amount": 1}Deplasmandan sayı siler.

Mola

Uç noktaGövdeAçıklama
POST/home/timeouts/increment{"duration": 30}Ev sahibi mola alır, geri sayım başlar (set başına en fazla 2).
POST/away/timeouts/increment{"duration": 30}Deplasman mola alır.
POST/home/timeouts/decrement—Ev sahibinin mola sayısını 1 azaltır.
POST/away/timeouts/decrement—Deplasmanın mola sayısını 1 azaltır.
POST/timeout/end—Devam eden molayı bitirir.

Servis

Uç noktaAçıklama
POST/serve/toggleServisi diğer takıma geçirir.
POST/home/serveServisi ev sahibine verir.
POST/away/serveServisi deplasmana verir.

Set

Uç noktaGövdeAçıklama
POST/set/end{"winner": "home"}Seti bitirir. winner verilmezse sayısı yüksek olan kazanır. Maç bitmediyse set arasına geçilir, taraflar değişir.
POST/set/start—Set arasından yeni sete geçer.
POST/sides/swap—Takımların yerini değiştirir.

Saat

Uç noktaAçıklama
POST/timer/toggleSet saatini başlatır / durdurur.
POST/timer/startSet saatini başlatır.
POST/timer/pauseSet saatini durdurur.
POST/timer/resetSet saatini sıfırlar.

Ekran ve diğer

Uç noktaAçıklama
POST/history/showYayın ekranında sayı geçmişini gösterir.
POST/result/showYayın ekranında maç sonucunu gösterir.
POST/undoSon işlemi geri alır.

Cevaplar

Başarılı yazma işlemleri message ve güncel board verisini döner:

{
  "message": "home score +1",
  "board": { "teamA": { "points": 12, ... }, "teamB": { ... }, ... }
}
KodAnlamı
200Başarılı
400İşlem yapılamadı (message nedenini söyler)
404Skorboard veya uç nokta bulunamadı
405Yanlış HTTP metodu
429Çok fazla istek

Hız sınırı

  • Skorboard başına saniyede en fazla 5 istek.
  • Aşılırsa 1 dakika boyunca tüm istekler 429 döner (Retry-After başlığı ile).

CORS

Tüm cevaplar Access-Control-Allow-Origin: * gönderir; API doğrudan tarayıcıdan çağrılabilir.
